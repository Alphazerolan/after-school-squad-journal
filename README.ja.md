### 放課後小队手账本

**放課後のひとときを、手帳の一ページに。**

> **使用許可の確認前 · イラスト使用のご相談用**

**Koe@寝不足** 様にイラストの使用イメージをご確認いただくためにまとめた、DeepSeek Harness 向け手帳風スキンの展示資料です。青い方眼紙、リング、付箋、マスキングテープで、会話と設定画面を一冊の手帳のようにまとめました。

個人制作の非商用デザイン試作であり、イラストの使用許可はまだ確認できていません。このリポジトリにはプレビュー、説明、出典リンクのみを掲載し、スキン本体・インストーラー・単独の原画素材は配布していません。作者様や DeepSeek との公式コラボレーションではありません。

## 01 · メイン画面

![青い方眼紙、リング、写真フレーム、付箋風の入力欄を組み合わせたメイン画面](previews/main-interface.png)

《UNOタイム》を写真のようなフレームに配置。会話一覧をインデックスカード、入力欄を青い方眼の付箋に見立て、紙のタブやテープ、重ねた紙の縁でつなげています。

> 現在のスキンのスタイルとデモ用レイアウトで再現した画面です。会話・アカウント・使用量は展示用の内容です。

## 02 · 設定ページに収めた、六つの日常

設定項目の下にイラストを配置し、ナビゲーションや操作欄、手帳の装飾と一緒に見られる形にしました。画像をクリックすると大きく表示できます。

> 既存のスキンのスタイルと代表的な設定項目を使って再現した模擬画面です。操作欄と下部のイラストを一緒に見せるため、通常はスクロールする内容を縦に展開しています。実行中のアプリをそのまま撮影した画像ではありません。画像内の UI 表記は中国語のままです。
