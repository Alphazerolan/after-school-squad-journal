# After-School Squad Journal

## 放課後小队手账本

**把放课后的好时光，收进每一页。**

青い方眼紙、リング、付箋、マスキングテープで、会話の画面を一冊の手帳に。

**イラスト使用のご相談用 / 授权确认中 · 设计展示**

このリポジトリは、DeepSeek Harness 向けに個人制作しているスキンの見た目を、イラストレーターの **Koe@寝不足** 様にご確認いただくための展示資料です。使用許可をいただいたことを示すものではありません。現在はプレビュー画像と作品の出典のみを掲載しており、スキン本体・インストーラー・原寸イラスト素材は配布していません。

这是为方便 **Koe@寝不足** 老师查看插画在界面中的使用方式而整理的公开展示稿。当前为个人非商业设计原型，**插画使用授权尚未确认**。仓库提供效果图、设计介绍与作品来源，暂不提供完整皮肤、安装包或独立原画素材。它不是画师或 DeepSeek 的官方合作项目。

## 01 · メイン画面 / 主界面

![主界面：蓝色方格纸、活页环、相纸背景与便签输入框](previews/main-interface.png)

《UNOタイム》作为相纸中的主画面。左侧的会话像一张张档案卡，输入框则是一张蓝色方格便签，用纸签、胶带和叠纸边缘连接起来。

《UNOタイム》を大きな写真のように配置。会話一覧をカード、入力欄を青い方眼の付箋に見立てています。

> 此图使用当前皮肤样式在演示界面中重建；会话、账号和用量均为展示数据。 / 現在のスタイルを使ったデモ画面です。会話・アカウント・使用量は展示用の内容です。

## 03 · 夏の気配 / 宠物页的夏日一角

![夏の気配：相纸、纸胶带、纸签与柠檬汽水装饰](previews/summer-pets.png)

把《夏の気配》放进宠物设置页，搭配纸胶带、回形针和柠檬汽水装饰。此处展示的是横向取景的布局，作品原图请见下方来源。
